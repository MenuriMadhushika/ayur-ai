# AyurAI

### AI-Powered Ayurvedic Skin & Wellness Platform

**AyurAI** is an ongoing full-stack software engineering project that explores the integration of **Artificial Intelligence, modern web technologies, and Ayurvedic wellness concepts**.

The platform uses deep-learning models to provide AI-assisted visual skin analysis while offering separate Ayurvedic wellness features such as Dosha assessment, sensitivity assessment, overall wellness results, and educational self-care guidance.

AyurAI is built using **React, Spring Boot, FastAPI, MySQL, PyTorch, and Docker**.

> **Project Status: Ongoing Development**
>
> AyurAI is an educational and portfolio project. It does not provide medical diagnosis or treatment and should not replace professional healthcare advice.

---

## Project Overview

AyurAI is being developed as a multi-service full-stack application where users can upload a facial image for AI-assisted skin analysis and separately complete Ayurvedic wellness assessments.

The current system includes two independent deep-learning models:

- **EfficientNet-B0** for four-class skin type classification
- **MobileNetV3 Small** for acne-like appearance estimation

The project also includes:

- User registration and authentication
- User profile management
- AI-powered Skin Scan
- Optional skin sensitivity questionnaire
- Skin scan history
- Ayurvedic Dosha assessment
- Overall result
- Educational home-remedy and self-care guidance
- Admin dashboard

The AI skin-analysis features and Ayurvedic wellness features are intentionally kept separate.

**Dosha results do not modify AI model predictions.**

---

## Key Features

### AI Skin Type Classification

AyurAI uses an **EfficientNet-B0** model to estimate four visual skin-type categories:

- Normal
- Oily
- Dry
- Combination

Skin type is presented as the primary visual skin-analysis result.

---

### Acne-Like Appearance Estimation

A separate **MobileNetV3 Small** model estimates visible acne-like appearance using four categories:

- Mild
- Moderate
- Severe
- Very Severe

This is presented as a secondary AI result.

Low-confidence predictions can be reported as **Uncertain**.

> Prediction confidence represents how confident the model is about its classification. It does not represent acne severity.

---

### Skin Sensitivity Assessment

Skin sensitivity is not treated as an image classification category.

Instead, AyurAI provides an optional questionnaire that records user-reported sensitivity signs.

Possible states include:

- Sensitivity reported
- Few sensitivity signs reported
- Not assessed

This keeps the sensitivity assessment separate from the visual AI classification.

---

### Skin Scan History

Authenticated users can access previously saved skin-analysis results.

This allows users to review relevant information from earlier scans while demonstrating persistent communication between the AI service, Spring Boot backend, and MySQL database.

---

### Ayurvedic Dosha Assessment

AyurAI includes a separate wellness questionnaire based on the traditional Ayurvedic Doshas:

- Vata
- Pitta
- Kapha

The Dosha assessment is a wellness feature.

It is not part of the machine-learning skin-analysis pipeline and does not modify predictions generated by the AI models.

---

### Overall Result

The Overall Result feature presents relevant saved skin and wellness information in an understandable interface.

Information can include:

- Skin type
- Acne-like appearance estimate
- Sensitivity assessment
- Dosha assessment
- Related wellness guidance

AI skin-analysis information and Ayurvedic wellness information remain conceptually separate.

---

### Home Remedies & Self-Care

AyurAI provides educational Ayurvedic home-remedy and self-care content.

This information is intended for general wellness and educational purposes rather than medical treatment.

---

### Authentication & User Profile

The application currently supports:

- User registration
- User login
- JWT authentication
- BCrypt password hashing
- Protected API endpoints
- User profile
- Resource ownership validation

---

### Admin Dashboard

AyurAI includes an administrative dashboard for relevant system-level information and management functionality.

Administrative functionality is protected separately from normal user functionality.

# AI Models

AyurAI currently integrates two independent deep-learning models.

## 1. EfficientNet-B0 — Skin Type Classification

**Purpose:** Four-class visual skin type classification

### Classes

```text
Combination
Dry
Normal
Oily
```

### Current Evaluation Results

| Metric | Result |
|---|---:|
| Held-out Test Accuracy | **81.37%** |
| Macro F1 | **0.7895** |
| Weighted F1 | **0.8155** |

These metrics represent the performance of the **skin-type classifier on its held-out test set**, not the accuracy of the entire AyurAI platform.

The dataset is not perfectly balanced, and the Combination class contains fewer samples than some other classes. Therefore, the results should be interpreted as experimental machine-learning performance rather than clinical accuracy.

---

## 2. MobileNetV3 Small — Acne-Like Appearance Estimation

**Purpose:** Visual acne-like appearance estimation

### Categories

```text
Mild
Moderate
Severe
Very Severe
```

The acne-like model operates independently from the skin-type classifier.

Its output is intended as an educational appearance estimate and not as a clinical acne diagnosis.

# Skin Scan Workflow

The Skin Scan feature allows users to upload a supported facial image for AI-assisted analysis.

The image follows this service flow:

```text
React Frontend
      ↓
Spring Boot Backend
      ↓
FastAPI AI Service
      ↓
PyTorch Models
      ↓
Prediction Results
      ↓
Spring Boot Backend
      ↓
React Frontend
```

The result can include:

- Predicted skin type
- Skin type confidence
- Acne-like appearance estimate
- Acne prediction confidence
- Analysis status
- Sensitivity information when assessed

# Responsible AI & Limitations

AyurAI is being developed as an **educational software engineering and machine-learning project**.

AI predictions have limitations and may be affected by factors including:

- Lighting conditions
- Camera quality
- Image resolution
- Face angle
- Makeup
- Shadows
- Skin visibility
- Environmental conditions
- Dataset limitations
- Class imbalance

For this reason, AyurAI does not present its AI outputs as medical diagnoses.

### Skin Type

```text
AI visual classification
≠
Dermatological diagnosis
```

### Acne-Like Appearance

```text
AI appearance estimate
≠
Clinical acne diagnosis
```

### Sensitivity

```text
User-reported questionnaire
≠
AI visual diagnosis
```

### Dosha

```text
Ayurvedic wellness assessment
≠
Machine-learning prediction
```

Users with medical or dermatological concerns should consult an appropriately qualified healthcare professional.
